FAFATRAINING RECETTES
=====================

Application PWA de cuisine et nutrition.

Cette archive contient une seule base propre prête pour GitHub Pages.
- index.html est directement à la racine.
- aucun ancien ZIP, script de migration ou sauvegarde n'est inclus.
- catalogue : 810 recettes uniques.
- menus : 100 menus complets, références valides et combinaisons uniques.
- navigation : Accueil / Recettes / Mon frigo / Organiser / Courses.
- recettes : préparation pas à pas, portions, matériel, allergènes, nutrition indicative lorsqu'elle est cohérente.
- cuisines : regroupement régional clair, avec Îles & Caraïbes et distinction tradition / adaptation / inspiration.

Déploiement GitHub Pages : copier le contenu de l'archive à la racine du dépôt fa-recettes.
