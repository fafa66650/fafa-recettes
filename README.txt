FAFATRAINING RECETTES — V10
============================

Cette version est une PWA orientée cuisine et nutrition.

PRINCIPALES ÉVOLUTIONS
- 354 recettes au total.
- 10 recettes FAFATRAINING issues des visuels transmis.
- 16 menus complets, centrés uniquement sur la cuisine.
- Navigation mobile : Accueil / Recettes / Menus / Mon frigo / Courses.
- Mode préféré mémorisé : Thermomix TM6, cuisine classique ou autre appareil.
- Styles de cuisine (express, facile, familiale, maison, légère, etc.) au lieu de niveaux débutant/expert.
- Favoris persistants.
- Filtres par catégorie, temps, matériel et style.
- Mon frigo : classement des recettes selon les ingrédients disponibles.
- Liste de courses persistante, regroupée par rayon.
- Fiches recettes avec portions ajustables.
- Mode cuisson étape par étape avec minuteur.
- PWA installable et cache hors connexion.

IMPORTANT
Les valeurs nutritionnelles sont affichées comme estimations par portion. Certaines recettes historiques de la V9 utilisent encore des instructions génériques héritées de la base d'origine. La V10 améliore fortement l'expérience et enrichit le catalogue, mais une validation culinaire recette par recette reste recommandée avant diffusion commerciale à grande échelle.

OUVERTURE
Pour tester localement, utiliser un petit serveur web dans le dossier, par exemple :
python3 -m http.server 8080
puis ouvrir http://localhost:8080

Sur téléphone, l'application est destinée à être hébergée en HTTPS afin de pouvoir être installée comme PWA.
