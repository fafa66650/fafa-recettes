FAFATRAINING RECETTES — VERIFICATION DU PACKAGE
================================================

Cette archive constitue la base propre actuelle de FAFATRAINING RECETTES.
Elle ne contient ni ancienne archive, ni dossier de version historique, ni fichier temporaire.

CONTROLES TECHNIQUES
- index.html directement à la racine du package.
- app.js : syntaxe JavaScript validée avec Node.js.
- recipes.json : JSON valide, 838 recettes, 838 identifiants uniques, 838 noms uniques.
- menus.json : JSON valide, 100 menus, 100 identifiants uniques.
- manifest.json : JSON valide.
- aucune référence de menu vers une recette inexistante.
- aucun identifiant HTML dupliqué.
- aucun fichier strictement dupliqué dans le package.
- aucun ancien marquage V10 à V18 détecté.
- aucun ZIP, .bak, .old ou fichier temporaire inclus dans le package.
- aucun doublon de nom après normalisation.
- aucune signature d'ingrédients exactement dupliquée détectée.
- service worker en stratégie réseau d'abord, cache en secours.
- chemins relatifs compatibles avec GitHub Pages sous /fa-recettes/.

ERGONOMIE CONSERVEE
- navigation principale : Accueil / Recettes / Mon frigo / Organiser / Courses.
- Menus et Planning regroupés sous Organiser.
- accueil recentré sur trois décisions principales et trois idées.
- cartes recettes cliquables et fiche recentrée sur « Commencer à cuisiner ».
- Mon Frigo simplifié.
- mode cuisson avec lecture vocale, répétition, minuteur et maintien d'écran lorsque disponible.

RECETTES CLASSIQUES RENFORCEES
Les fiches existantes suivantes ont été réécrites pour être réellement réalisables et pédagogiques :
- Crêpes faciles ;
- Muffins myrtilles ;
- Cake au citron ;
- Cheesecake léger fruits rouges.

NOUVELLES RECETTES REELLES ET DISTINCTES
- Gaufres de Bruxelles — Belgique · Bruxelles ;
- Galettes bretonnes de sarrasin — France · Bretagne ;
- Cheesecake new-yorkais — États-Unis · New York ;
- Quatre-quarts breton — France · Bretagne ;
- Cake marbré vanille chocolat — recette maison ;
- Muffins double chocolat — recette maison.

Pour ces fiches, les étapes classiques détaillent les quantités, températures, durées, textures et repères de cuisson. Le TM6 est utilisé en aide lorsque pertinent ; la cuisson nécessitant poêle, four ou gaufrier reste explicitement réalisée avec l'appareil adapté. Les anciennes estimations nutritionnelles des fiches profondément modifiées ont été retirées lorsqu'elles n'étaient plus fiables, en attendant un recalcul depuis les ingrédients normalisés.

REGLE DE CONTENU
La priorité reste la qualité, la diversité réelle et la faisabilité. Aucune origine géographique ne doit être inventée pour créer artificiellement de la variété. Les futures recettes doivent rester distinctes par leurs ingrédients, techniques, accompagnements et usages culinaires.
